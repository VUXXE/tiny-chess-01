A 4 KB Python chess engine: 0x88 board, negamax alpha-beta search with a transposition table, null-move pruning, late move reductions, quiescence search and a tapered piece-square evaluation with pawn structure. Python 3.13 standard library only, a single file, no other files read.

## Run it

```sh
python3 -P -s /bot/main.py
```
